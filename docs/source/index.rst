SIS-Meta documentation
======================

``sis_meta`` is a Python package for handling ``.meta`` files. These are 
annotation files generated by `SIS (Ikar Lab)`_, an audio forensic software.

If you find this project useful, please consider to support it. 

.. _SIS (Ikar Lab): https://speechpro.com/product/forensic_analysis/ikarlab-3#tab3
