# sis-meta

[![PyPI - Version](https://img.shields.io/pypi/v/sis-meta.svg)](https://pypi.org/project/sis-meta)
[![PyPI - Python Version](https://img.shields.io/pypi/pyversions/sis-meta.svg)](https://pypi.org/project/sis-meta)

-----
``sis_meta``  is a Python package for handling ``.meta`` files. These are annotation files generated by [SIS (Ikar Lab)](https://speechpro.com/product/forensic_analysis/ikarlab-3#tab3), an audio forensic software.
